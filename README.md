# Semangat ya, Seninnya!

Web ucapan semangat hari Senin buat Mona, dengan tema pink dan dua interaksi:

- **Survival Kit:** buka tiga bekal untuk membaca pesan dari teman.
- **Bunga Semangat:** siram bunga tiga kali sampai mekar.

`index.html` sudah berisi CSS, JavaScript, dan gambar. Bisa dibuka langsung tanpa instalasi atau internet.

## Hosting di GitHub Pages

Di **Settings → Pages**, pilih **Deploy from a branch**, branch **main**, dan folder **/ (root)**, lalu simpan.

Repository private memerlukan paket GitHub yang mendukung Pages. Pada GitHub Free, gunakan repository public.

Untuk mengubah pesannya, edit teks di `index.html`. Pesan interaktif ada di bagian `gifts` dan `growth`.
